### Security
- On Windows, the approval dialog of the secret vault, the Windows Credential Manager backend and `zn secret set --clipboard` now start the system PowerShell found through the kernel's `\SystemRoot` link, as `zn run` already did for `cmd.exe`, instead of the path in the `SystemRoot` variable, which an AI agent running zn can change. Without the system PowerShell, the dialog is not shown (approvals are refused) and the Credential Manager backend reports an error.
