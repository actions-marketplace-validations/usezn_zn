### Security
- The audit log (`~/.zn/evidence.jsonl`) is now checked for damage before anything is read or added. A log with unreadable bytes or a cut-off last line is reported as corrupted, with the line number, by `evidence --verify` (non-zero exit), `evidence` and `evidence --export`, instead of failing with a Python error. A damaged log is never used to start a new chain: the event is not written, a single warning is shown, and your command or agent carries on as usual. Run `zn-gate evidence --verify` to see what is wrong. An empty or missing log still starts a fresh chain.
