### Security
- The agent hooks: reading a `.env` or credential file from the git repository (`git show HEAD:.env`, `git cat-file -p :app/.env`) or its history (`git log -p -- .env`, `git checkout HEAD -- .env`, `git archive HEAD .env`) is refused, like reading it from disk, also when the file is no longer on disk. `git rm --cached .env`, `git status` and `git check-ignore .env` still work. `POLICY_RULES_VERSION` is `2026-10-17.7`.
