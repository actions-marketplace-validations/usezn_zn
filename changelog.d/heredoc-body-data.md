### Fixed
- The hook no longer refuses a command that writes a file from a here-document (`cat > file <<'EOF'`) when the body holds a `*` or another glob character, and it checks a 100 KB body in a few milliseconds instead of tens of milliseconds.
- A here-document body is only read as data in a plain simple data command (`cat`, `tee`, `dd`, ...) with no pipe, process substitution or group before it. Bodies a shell, an interpreter or `xargs` runs, bodies piped to a shell, and a script the same command writes and then runs, are still refused, and every read of `.env` or a credential file on the command line is refused as before. The check is linear with the existing time budget, so 10 000 here-document operators on one line stay within it.
