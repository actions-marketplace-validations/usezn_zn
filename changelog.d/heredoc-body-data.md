### Fixed
- The hook no longer refuses a command that writes a file from a here-document (`cat > file <<'EOF'`) when the body holds a `*` or another glob character, and it checks a 100 KB body in a few milliseconds instead of tens of milliseconds.
- A here-document body is only read as data in a plain simple data command (`cat`, `tee`, `dd`, ...) with no pipe, process substitution or open group (also one opened on an earlier line, and the `)` of a `case` pattern does not close a group). Bodies a shell, an interpreter, `xargs` or `parallel` runs, bodies piped to a shell, a program with an option that runs code (`sort`, `split`), a command that redefines a function or `PATH`, and a file the same command writes and then runs (also by an absolute path, also behind `nohup`, `timeout` or `exec`), are still refused. Every read of `.env` or a credential file on the command line is refused as before. The check is linear with the existing time budget, so 10 000 here-document operators or 50 000 parentheses on one line stay within it.
