### Added
- `zn-gate reach [path]` shows, in one screen, what the coding agents on this machine can reach: which agents are found and whether zn protects them, the `.env` files of the folder with the names of their secrets, the credential files in your home folder (`~/.aws/credentials`, SSH keys, `~/.npmrc` and others: checked only for whether they exist, never opened), the names of environment variables that hold a secret, and what `zn audit` finds in the MCP servers and agent settings of the folder and of your user. Each finding has the command that fixes it. It is read only: no value is ever shown, nothing is written or sent, and no hook is started. `--json` gives the same report as JSON. It always exits 0.
