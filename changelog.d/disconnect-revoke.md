### Changed
- `zn-gate disconnect` now asks whether to also revoke the saved key on usezn.com, so it stops working everywhere (the default is no). Only an explicit yes sends anything: one request with the key to https://api.usezn.com, over the same checked connection `connect` uses. The local copy is removed in every case, even if the request fails, and a failed revoke tells you and links https://usezn.com/api-keys. `--revoke` skips the question and `--no-revoke` never revokes. With no terminal, or from an AI agent, the command still refuses and nothing is revoked. zn-gate still needs no account and sends nothing by default. See [docs/connect.md](docs/connect.md).
- The `connect` help now says it takes an analysis-only API key.
