### Changed
- `zn-gate disconnect` now asks whether to also revoke the saved key on usezn.com, so it stops working everywhere (the default is no). Only an explicit yes sends anything: one request with the key to https://api.usezn.com, over the same checked connection `connect` uses. The local copy is removed in every case, even if the request fails, and a failed revoke tells you and links https://usezn.com/api-keys. In your own terminal, `--revoke` skips the question and `--no-revoke` never revokes. `disconnect` only runs in your own terminal: from a script or an AI agent it refuses and changes nothing, with or without those options. zn-gate still needs no account and sends nothing by default. See [docs/connect.md](docs/connect.md).
- The `connect` help now says it takes an analysis-only API key.
